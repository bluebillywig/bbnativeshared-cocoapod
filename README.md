# BlueBillywigNativeShared-iOS

Shared business logic framework used by [BlueBillywigNativePlayerKit-iOS](https://github.com/bluebillywig/bbnativeplayerkit-cocoapod). This module contains the cross-platform core — controllers, data models, networking, and event handling — that powers the Blue Billywig Native Player SDK on iOS.

> **This is an internal dependency.** Do not add this package to your app. It comes in automatically when you add the `BlueBillywigNativePlayerKit-iOS` package. See the [PlayerKit repository](https://github.com/bluebillywig/bbnativeplayerkit-cocoapod) for integration instructions.

## Requirements

- iOS 14.0+

## Installation

### Swift Package Manager

Swift Package Manager resolves this package when you add `BlueBillywigNativePlayerKit-iOS`. You do not add it yourself.

> **CocoaPods:** version 8.64 is the last version on CocoaPods and gets no further updates. Move to Swift Package Manager; [the migration guide](https://support.bluebillywig.com/native-sdk/ios-sdk-cocoapods-to-swift-package-manager/) has the steps.
